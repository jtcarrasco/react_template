# React Template

Vite + React SPA scaffold with React Router v6 and a fetch-from-API example.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Requirements

- Node 22+, npm 10+

## Demo Content

- Home with API data fetched from JSONPlaceholder
- About page
- 404 catch-all route
- React Router v6 nested layout pattern

## Build

```bash
npm run build   # outputs to dist/
```
